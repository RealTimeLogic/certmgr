Configuration

Private-key protection

Active:

This database is protected for this computer.

Mako Server protects each new private key with a key derived specifically for this computer. The database is not transferable for operational use because another computer cannot decrypt those private keys.

Copying the database can still provide a local recovery copy, but it is not a portable backup.

Need a portable database? Set certmgr.keyMode="global" in mako.conf, point dbdir to a new empty database location, and restart Mako Server before creating the certificate authority. Changing the setting does not convert keys already created in unique mode.

This database can move within its configured trust domain.

Mako Server protects new private keys with a key shared by an administrator-configured trust domain. The database can be transferred only to another Mako Server installation in that same trust domain.

Global mode enables controlled portability; the database still contains sensitive encrypted key material and must be protected.

Current setting: certmgr.keyMode="" in mako.conf. Existing records retain the protection mode used when they were created; changing this setting affects new keys only. Global mode makes encrypted records portable within their configured trust domain; it does not make Certificate Manager public or remotely accessible.
